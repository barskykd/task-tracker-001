
# Тестовое задание - Веб приложение для управления задачами

## Запуск приложения

`docker compose up`

После запуска приложение доступно на http://127.0.0.1:8000
Логин/пароль по умолчанию: admin/admin
Можно также зайти с использованием Google OAuth

## Запуск автоматических тестов

`docker compose --profile pytest up`
